# Smart Utility Management System

A centralized utility management platform for managing electricity, water, and gas services with billing, meter tracking, tariff management, and secure department-based access control.

## Features

* Consumer and service connection management
* Meter reading and consumption tracking
* Automated bill generation
* Tariff and payment management
* Department-wise authentication and authorization
* Payment history tracking
* Relational database design with normalization (3NF)

## Tech Stack

* Frontend: React.js
* Backend: Node.js, Express.js
* Database: MySQL

## Modules

* Consumer Management
* Service Connection Management
* Meter Management
* Billing System
* Payment Tracking
* Tariff Management
* Authentication & Authorization

## Database Concepts Used

* ER Modeling
* Normalization (3NF)
* Referential Integrity
* SQL Queries and Constraints
